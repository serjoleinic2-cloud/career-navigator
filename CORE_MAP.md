# CORE_MAP.md — карта `src/core`

Автосгенерировано анализом импортов (`grep` по всему `src`) + первого экспорта/комментария каждого файла. Актуально на момент коммита; при добавлении/удалении файлов в `src/core` — перегенерировать (скрипт можно попросить у Claude/OpenCode).

**Как читать `used_by`:** сколько других файлов в `src` реально импортируют этот модуль (по подстроке пути). `used_by=0` не гарантирует 100%, что файл мёртв (могут быть косвенные реэкспорты через `index.ts` не учтённые грубым grep), но в этом проекте — судя по объёму `update`-коммитов и параллельным веткам архитектуры — таких файлов **подавляющее большинство**, и это, вероятно, реальная картина: параллельные, не подключённые версии engine/движков, оставшиеся от предыдущих итераций.

**Прежде чем удалять файл с `used_by=0`:** проверьте его `index.ts` в той же папке — иногда точка входа реэкспортирует наружу что-то, что использует barrel-импорт (`from '@/core/xxx'`), который грубый grep по прямому пути файла не поймает 100% случаев.
