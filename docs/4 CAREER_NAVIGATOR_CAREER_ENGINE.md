# CAREER_NAVIGATOR_CAREER_ENGINE

Version: 1.0

This document defines the progression system, scoring model, chapter structure, task rules, confidence system, and journey generation logic.

---

# CORE PRINCIPLE

The application does not teach.

The application moves the user toward employment through structured action.

Progress is measured through completed actions, consistency, and readiness indicators.

---

# CAREER JOURNEY STRUCTURE

# GAP ANALYSIS

Purpose

Compare confidence and preparation.

---

Scenario 1

Confidence > Readiness

Result

Possible overconfidence.

Recommendation

More practice.

---

Scenario 2

Confidence < Readiness

Result

Possible underconfidence.

Recommendation

Begin interviewing sooner.

---

Scenario 3

Confidence ≈ Readiness

Result

Healthy self-awareness.

Recommendation

Continue journey.
