# CAREER NAVIGATOR
## MASTER GUIDE

Этот документ является главным источником информации по проекту.

Любая новая сессия Claude обязана сначала ознакомиться с данным документом и использовать его как единственный источник истины.

Запрещено придумывать новые функции, экраны или механики без проверки соответствия этому документу.

---

# PROJECT STATUS

Текущий этап разработки определяется разделом Roadmap.

Перед началом работы Claude должен определить:

1. Какой раздел уже завершён.
2. Какой раздел находится в работе.
3. Какой раздел следующий.

Если информации недостаточно, Claude должен запросить соответствующий документ.

# WORKFLOW RULES

При старте новой сессии Claude обязан:

Шаг 1

Изучить данный MASTER GUIDE.

Шаг 2

Спросить:

"Какой документ мы сейчас разрабатываем?"

Шаг 3

Если документ отсутствует:

создать его.

Шаг 4

Если документ существует:

продолжить работу только внутри него.

# IMPORTANT RULE

Главный принцип продукта:

Пользователь не проходит курс.

Пользователь движется по маршруту к трудоустройству.

Все решения должны поддерживать эту идею.
