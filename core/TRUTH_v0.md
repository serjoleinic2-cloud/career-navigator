# What is system

Career Navigator — мобильное приложение (React + Capacitor + Android), которое помогает пользователям строить карьерный путь: выбирать цели, получать пошаговые планы развития и отслеживать прогресс.

Career Engine — логическое ядро приложения. Принимает цель пользователя, возвращает карьерные опции и набор шагов для каждой опции. На текущем этапе — заглушка (mock), без AI.

## Modules

| Модуль | Описание |
|--------|----------|
| UX Flow | Пользовательский сценарий: выбор цели → путь → шаги |
| Career Engine | Логика подбора карьерных опций и шагов (stub) |
| Content System | Контент: developerPath.ts, узлы и связи |
| Interview Trainer | Тренажёр собеседований (в разработке) |
