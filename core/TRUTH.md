# TRUTH

Этот файл — единственный источник истины о структуре проекта CareerNavigator.

## Структура

- /core     — ядро: истина, правила, контроль
- /engine   — логика Career Engine
- /ui       — переиспользуемые UI-компоненты
- /flows    — пользовательские сценарии (flows)
- /tools    — вспомогательные утилиты
- /src      — React-приложение (frontend)
- /android  — Android-сборка Capacitor
- /docs     — документация

## Правило

Истина только здесь. Никакие другие файлы не переопределяют структуру.
