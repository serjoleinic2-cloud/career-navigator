# IMPLEMENTATION PATCH — Offline Interview Trainer

Цель: реализовать полноценный Interview Trainer для Career Navigator.

Не менять Runtime.
Не менять Event Bus.
Не создавать новую систему задач.
Использовать существующие TaskContent, SkillNode и Runtime.

---

# Использовать существующие модели

* src/core/task_content.ts
* src/core/skill_state.ts
* src/core/runtime/runtime_controller.ts

Не создавать InterviewQuestionModel.

Не создавать InterviewEngine.

TaskContent уже является источником данных.

Маппинг:

```text
TaskContent.title                 → карточка задания
TaskContent.objective             → вопрос интервьюера
TaskContent.instructions          → подсказки
TaskContent.completionCriteria    → критерии оценки
TaskContent.tips                  → рекомендации после ответа
TaskContent.expectedOutcome       → эталон результата
```

# Реализовать TTS

В tts.ts реализовать настоящий wrapper над Web Speech API.

API:

```ts
speak(
    text: string,
    options?: {
        rate?: number;
        pitch?: number;
        volume?: number;
        voiceName?: string;
    }
)

stop()

isSpeaking()
```

Использовать:

speechSynthesis

SpeechSynthesisUtterance

Если speechSynthesis отсутствует —

функции должны безопасно завершаться без ошибок.

Не использовать сторонние библиотеки.

Работа полностью офлайн.

Используются системные голоса устройства.
