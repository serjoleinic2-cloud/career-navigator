BUG 1 — UI optimistic completion

ISSUE:
MissionScreen sets:
setTaskView('completed')
immediately after emit('MISSION_SUBMIT')

PROBLEM:
UI shows success before skill_engine confirms result.

FIX:
Remove immediate completion state change.

REPLACE FLOW WITH:

1. emit('MISSION_SUBMIT')
2. WAIT for 'MISSION_RESULT' event from skill_engine
3. ONLY THEN setTaskView('completed')

--------------------------------------

BUG 2 — missing MISSION_RESULT event

CHECK skill_engine.ts:

REQUIRED:
After processing submitTask(), MUST emit:

emit('MISSION_RESULT', {
  success: boolean,
  updatedState: JourneyRuntimeState
});

If missing → ADD IT.

--------------------------------------

BUG 3 — UI does not handle MISSION_RESULT

IN MissionScreen.tsx:

ADD listener:

on('MISSION_RESULT', (payload) => {
  if (payload.success) {
    setTaskView('completed');
  } else {
    setTaskView('active');
    show error state (simple retry UI or shake animation)
  }
});
