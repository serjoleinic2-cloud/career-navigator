TITLE: CAREER NAVIGATOR — ARCHITECTURE MERGE (CRITICAL REFACTOR)

GOAL:
Unify architecture. Remove duplicate game systems. Establish single source of truth.

There are 3 overlapping systems:
1. JourneyScreen (legacy UI + partial logic)
2. world_renderer (game-like visualization attempt)
3. skill_engine (true core logic system)

This causes duplicated state handling and conflicting rendering logic.

FINAL ARCHITECTURE (MANDATORY):

skill_engine (SOURCE OF TRUTH)
        ↓ emits state
world_renderer (ONLY VISUAL RENDER LAYER)
        ↓
MissionScreen (ONLY INTERACTION LAYER)

--------------------------------------

1. skill_engine (DO NOT CHANGE LOGIC)

  - careerState

Refactor world_renderer to become the PRIMARY GAME VIEW.

- MUST consume ONLY skill_engine state
- MUST NOT calculate any logic
- MUST NOT mutate state
- MUST ONLY render visual representation of:
  - nodes

  - progression state

RULE:
state → pure visual output ONLY

  - fallback debug screen OR legacy wrapper

JourneyScreen must NOT own gameplay logic anymore.

skill_engine
