MISSION CARD UX PATCH v1

Цель

Переделать отображение текущей задачи без изменения runtime, learning engine, event bus или persistence.

Использовать новые UI-компоненты:
- AppShell
- GlassCard
- PrimaryButton
- ProgressRing
- IconButton

Изменять только JourneyScreen и связанные UI-компоненты.

=========================================
УБРАТЬ
=========================================

Не выводить одновременно:

- Advice
- Signals
- Tasks
- Instructions
- Completion Criteria
- Tips

Не показывать длинный экран с большим количеством информации.

=========================================
MISSION FLOW
=========================================

После Start Mission

не открывать новый экран.

Развернуть карточку.

Показать только первый instruction.

Каждый instruction становится отдельным Step.

Структура:

Step 1

Текст

Done

После Done

раскрывается Step 2.

И так далее.

В каждый момент времени пользователь видит только один активный шаг.

=========================================
MISSION PROGRESS
=========================================

Над шагами

Mission Progress

например

2 / 4

и progress bar.

=========================================
HELP
=========================================

Под шагом

две маленькие кнопки

Need Hint

Open Playbook

Need Hint раскрывает tips.

Open Playbook вызывает существующий Playbook.

=========================================
MISSION REVIEW
=========================================

После последнего шага

показать карточку

Mission Review

Checklist:

Objective completed

Evidence prepared

Completion Criteria satisfied

Большая кнопка

Complete Mission

=========================================
MISSION RESULT
=========================================

После submitTask()

НЕ переходить на другой экран.

Показать красивую Result Card.

Mission Complete

XP gained

Readiness gained

Confidence gained

Unlocked

Next Mission

Кнопка Continue Journey

=========================================
COLLAPSIBLE
=========================================

Advice

Signals

Notes

внизу страницы.

Открываются независимо.

=========================================
РЕЗУЛЬТАТ

JourneyScreen становится экраном выполнения одной миссии.

Пользователь всегда понимает:

что делать сейчас,

какой следующий шаг,

сколько осталось,

что получит после завершения.

Предоставить IMPLEMENTATION REPORT и список изменённых файлов.
