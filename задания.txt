Я бы еще добавил один архитектурный принцип для всего проекта:

Runtime → UI ViewModel → World ViewModel → React Components

То есть мир никогда не строится из Runtime напрямую. Он строится только из UI-модели. Это даст вам возможность в будущем полностью заменить визуальный слой (например, перейти с React Native на Unity, Godot или Three.js) без единого изменения в runtime или learning engine. Это именно тот уровень развязки, который обычно используют в крупных игровых и обучающих проектах.
