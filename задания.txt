C1 — Два живых runtime-стейта
FILE: runtime_controller.ts + runtime_store.ts
runtime_controller.ts хранит модульную переменную runtimeState: JourneyRuntimeState | null. runtime_store.ts хранит отдельный state: UnifiedRuntimeState. runtime_engine.ts читает и пишет в store через getState/setState. runtime_controller.ts — в свою переменную. Они никогда не синхронизируются. UI_REFRESH приходит, JourneyScreen читает через getUIState() (который, судя по импорту, идёт через ui_bridge → вероятно, через store), а getActiveNode() читает напрямую из runtimeState. Гарантированный рассинхрон при любом событии.
FIX:
ts// runtime_controller.ts — убрать module-level var, делегировать в store
import { replaceState, getState } from './runtime_store';

export function getRuntimeState(): JourneyRuntimeState | null {
  return getState() as JourneyRuntimeState ?? null;
}
// Все места где runtimeState = { ...runtimeState, ... } → updateState(prev => ({...prev, ...}))

H2 — App.tsx: hash routing рассинхронизирован со state
FILE: App.tsx:28-33
Кнопка "Notes" в JourneyScreen делает window.location.hash = '#notes'. Это тригерит hashchange → setShowNotes(true). Кнопка назад делает window.location.hash = '' + setShowNotes(false). Но на Capacitor iOS hashchange не всегда файрится при programmatic change. Плюс: при первой загрузке onHashChange не вызывается — hash из URL не читается.
FIX:
tsuseEffect(() => {
  const onHashChange = () => { /* ... */ };
  window.addEventListener('hashchange', onHashChange);
  onHashChange(); // ← читаем hash при mount
  return () => window.removeEventListener('hashchange', onHashChange);
}, []);
PRIORITY: Must Fix

H4 — loadRuntime() не валидирует схему
FILE: runtime_persistence.ts
load<JourneyRuntimeState>() делает прямой cast JSON → тип. Если в localStorage лежит стейт от предыдущей версии без полей confidenceScore, chapterProgress и т.д. — всё упадёт в submitTask().
FIX:
tsexport function loadRuntime(): JourneyRuntimeState | null {
  const raw = load<Record<string, unknown>>(opts);
  if (!raw || typeof raw.professionId !== 'string' || !raw.nodeStates) return null;
  if (!('confidenceScore' in raw)) return null; // schema guard
  return raw as JourneyRuntimeState;
}
