IMPLEMENTATION PATCH — JourneyScreen CSS Integration

Цель: полностью стилизовать JourneyScreen в существующем проекте Career Navigator.

Не создавать новые компоненты.
Не менять runtime.
Не менять event bus.
Не менять бизнес-логику.

Изменить только UI и CSS.

Файлы

Создать (если отсутствуют):

src/screens/JourneyScreen/JourneyScreen.css

или

JourneyScreen.module.css

в зависимости от архитектуры проекта.

Подключить стили в JourneyScreen.tsx.
