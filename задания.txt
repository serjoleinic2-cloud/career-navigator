JOURNEY SCREEN UX REBUILD v1

Цель

Полностью перестроить JourneyScreen вокруг одной активной задачи.

Не менять runtime, learning engine, event bus, persistence.

Использовать новый AppShell и UI Framework.

=========================================
НОВАЯ СТРУКТУРА
=========================================

<AppShell>

TopBar

Scrollable Content

BottomNavigation

=========================================
1. HERO CARD
=========================================

Самая верхняя карточка.

Показывает только:

Chapter

Skill

Task X of Y

Readiness %

Confidence %

Большая ProgressRing.

Большая кнопка

Continue

или

Start Task

если задача ещё не открыта.

=========================================
2. TODAY'S MISSION
=========================================

Следующая большая карточка.

Название

Today's Mission

Внутри

Task Title

Objective

Estimated time

Difficulty

Кнопка

Start Mission

Это самая большая кнопка экрана.

=========================================
3. TASK FLOW
=========================================

После нажатия

Start Mission

экран НЕ открывает другую страницу.

Он раскрывает Mission Card.

Внутри появляются шаги.

Например

□□□□□□□□

Step 1

Read objective

кнопка

Done

□□□□□□□□

после Done

автоматически раскрывается

Step 2

□□□□□□□□

после Step2

раскрывается

Step3

□□□□□□□□

и так далее

Пользователь никогда не видит сразу длинную инструкцию.

Только один шаг одновременно.

=========================================

=========================================

Над шагами

Mission Progress

2 / 4

4 / 4

=========================================

✓ Criteria satisfied

=========================================
9. HEADER
=========================================

Header всегда остаётся сверху.

Back

Chapter

Settings

=========================================
10. UX RULES
=========================================

Никогда не показывать пользователю одновременно:

Advice

Signals

Instructions

Checklist

Playbook

Notes

Все открываются отдельно.

Один экран = одна задача.

=========================================
11. АНИМАЦИИ
=========================================

Раскрытие карточек

opacity + translateY

250ms

Кнопки

scale

Mission Complete

fade + scale

=========================================
12. НЕ ДЕЛАТЬ
=========================================

Никаких modal.

Никаких alert.

Никаких confirm.

Никаких длинных полотен текста.

=========================================
РЕЗУЛЬТАТ

После патча пользователь открывает приложение и за 3 секунды понимает:

Где я.

Что делать.

Сколько осталось.

Что получу после выполнения.

Весь интерфейс работает как последовательность маленьких действий, а не как экран с большим количеством информации.

Это будет фундамент UX. После него мы займемся JourneyPath, чтобы путь стал визуальной игрой, а не просто списком нод. Именно тогда приложение начнет напоминать Monument Valley, Elevate и Duolingo по ощущениям прохождения.
