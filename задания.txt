UI FOUNDATION PATCH v1

Цель:
Создать единый UI Layout для всего приложения. Не менять runtime, engine, event bus, persistence.

Создать компоненты:

src/components/layout/
  AppShell.tsx
  TopBar.tsx
  BottomNavigation.tsx
  GlassCard.tsx
  IconButton.tsx
  PrimaryButton.tsx
  ProgressRing.tsx

src/styles/
  layout.css
  theme.css
  animations.css

Результат.

После патча любой экран приложения можно собрать из готовых компонентов без копирования CSS.

Никакой бизнес-логики.

Только UI Framework.

После этого мы переделаем JourneyScreen полностью. Не косметически, а так, чтобы человек впервые открыв приложение, интуитивно понял:

где он находится;
что делать прямо сейчас;
