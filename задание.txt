TITLE: CAREER NAVIGATOR — PHASE A (GAME DESIGN FOUNDATION)

PRIORITY: CRITICAL

GOAL

Career Navigator must no longer look like a productivity app.

It must become an exploration game inspired by Monument Valley principles.

IMPORTANT

Do NOT copy Monument Valley assets or compositions.

Use only its design philosophy:

- calm
- minimalism
- impossible architecture
- vertical progression
- premium feeling
- emotional journey

====================================================

TASK 1 — CREATE DESIGN SYSTEM

Create a new folder:

src/design/

Add:

DesignSystem.ts
WorldTheme.ts
GameSpacing.ts
GameTypography.ts
GameColors.ts
GameElevation.ts
GameAnimation.ts

These files become the ONLY source of visual constants.

====================================================

TASK 2 — DEFINE WORLD LANGUAGE

Every visual element must belong to one universe.

Rules:

Platforms
Bridges
Stairs
Floating islands
Portals
Light beams
Clouds
Water
Fog
Glow
Stone
Glass

No modern flat UI.

No material cards.

No dashboard look.

====================================================

TASK 3 — DEFINE UI STYLE

Buttons are not rectangles.

Buttons feel like pieces of the world.

Cards feel carved into architecture.

Dialogs float above the world.

Progress bars become illuminated paths.

Checkboxes become glowing runes.

Locked content becomes sleeping architecture.

Completed content becomes illuminated architecture.

====================================================

TASK 4 — WORLD MAP PHILOSOPHY

World Map is NOT navigation.

World Map IS gameplay.

Player never navigates menus.

Player travels.

The camera follows the journey.

Future remains partially hidden.

Destination is always above.

====================================================

TASK 5 — PROFESSION MODULE RULE

Each profession is an independent world.

Every profession module owns:

world theme

palette

architecture

decorations

chapter icons

ambient particles

reward style

victory scene

No global art duplication.

====================================================

TASK 6 — DEFINE GAME COMPONENTS

Specify visual language for:

Active Node

Reward Chest

Loading Screen
