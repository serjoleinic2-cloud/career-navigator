TITLE: WORLD COMPOSITION LAYER — UNIFICATION OF WORLD SYSTEM

GOAL

Unify world rendering system so that:

- world_theme
- WorldBackdrop
- profession world modules
- progress state

become a single coherent system.

====================================================

TASK 1 — CREATE WORLD COMPOSER

Create:

src/core/world/world_composer.ts

Responsibilities:

- combine world_theme + profession module
- resolve geometry + palette + ambient settings
- output single WorldRenderConfig

DO NOT render anything here.

ONLY assemble data.

====================================================

TASK 2 — DEFINE WORLD RENDER CONFIG

Create type:

WorldRenderConfig:

- palette
- geometry
- atmosphere
- lighting
- camera
- backdrop
- particles (optional future)
- animation profile

====================================================

TASK 3 — MOVE RESPONSIBILITY OUT OF JOURNEYSCREEN

JourneyScreen must NOT:

- calculate world theme
- decide geometry
- manage world styling

It should ONLY:

- consume WorldRenderConfig
- pass it to WorldRenderer / WorldBackdrop

====================================================

TASK 4 — UNIFY WORLD BACKDROP INPUT

Modify:

WorldBackdrop.tsx

It must accept:

WorldRenderConfig

NOT hardcoded theme logic inside component.

====================================================

TASK 5 — PROFESSION MODULE STANDARDIZATION

Ensure:

Each profession exports:

world.ts:

- theme
- geometry
- ambient rules
- name
- unlock conditions (optional metadata only)

====================================================

TASK 6 — SINGLE SOURCE OF WORLD TRUTH

After this change:

ONLY world_composer decides final world state.

No duplication between:

- theme system
- backdrop system
- screen logic

====================================================

OUTPUT

Create:

WORLD_COMPOSITION_REPORT.md

Include:

- old architecture issues
- new data flow
- module boundaries
- risks
- migration notes

====================================================

CONSTRAINTS

No new screens.
No UI redesign.
No gameplay changes.

ONLY architecture unification of world system.
