# CAREER_NAVIGATOR_INTERVIEW_TRAINER

Version: 1.0

This document defines the full interview simulation system including question library, voice practice flow, evaluation system, progression logic, and training structure.

---

# CORE PURPOSE

The Interview Trainer is not a learning module.

It is a simulation system that trains real interview performance through repetition, self-observation, and structured feedback.

The goal is to make the user:

* sound confident
* answer clearly
* reduce hesitation
* build structured responses
* perform under pressure

---

# CORE LOOP

1. User receives interview question (voice or text)
2. User prepares briefly
3. User records answer (20–60 sec)
4. User listens to answer
5. User evaluates themselves
6. System provides structured feedback
7. Progress is updated

---

# QUESTION STRUCTURE

Each question contains:

* Question text
* Category
* Difficulty level
* Expected structure
* Common mistakes
* Evaluation checklist

# VOICE PRACTICE FLOW

## Step 1: Question Display

User sees or hears question.

---

## Step 2: Preparation Timer

5–10 seconds silence.

Purpose: simulate real interview pressure.

---

## Step 3: Recording

Duration:

20–60 seconds

Hard limit enforced.

---

## Step 4: Playback

User listens to own answer.

This step is mandatory.

---

## Step 5: Self Evaluation

Checklist:

* I spoke clearly
* I had structure
* I avoided filler words
* I stayed confident
* I did not ramble
* I answered directly

Rating:

1–10

---

## Step 6: System Evaluation

System does NOT use AI.

Uses rule-based evaluation:

* length of answer
* presence of structure markers
* repetition patterns
* skipped key elements
* hesitation indicators (manual input optional)

---

## Step 7: Feedback Output

Generated feedback includes:

Strengths

Improvement areas

One specific recommendation

---

# STRUCTURE EXPECTATION MODEL

Each answer should follow:

## Recommended structure:

Situation → Action → Result

or

Past → Present → Future

or

Problem → Solution → Outcome

---

# COMMON MISTAKES LIBRARY

## Mistake 1: No structure

User talks randomly without direction.

---

## Mistake 2: Too long answers

More than 90 seconds equivalent.

---

## Mistake 3: Weak language

"I think", "maybe", "I guess"

---

## Mistake 4: No result mention

Answer describes action but not outcome.

---

## Mistake 5: Nervous filler words

um, uh, like, you know

---

# FEEDBACK RULES

Feedback must always include:

1. One strength
2. One improvement
3. One actionable next step

No more than 3 points.

---

# PROGRESSION SYSTEM

## Session Completion

1 completed interview session = progress unit

---

## Milestones

# QUESTION GENERATION LOGIC

Questions are selected based on:

* profession
* experience level
* weak areas
* previous answers
* confidence level

---

# PERSONALIZATION RULES

If user is weak in:

Structure → more structured questions

Confidence → easier questions first

Experience → more behavioral questions

Fear → gradual exposure to harder questions

---

# SIMULATION MODES

## Mode 1: Practice

User can retry freely.

---

## Mode 2: Simulation

No retries. Real interview conditions.

---

## Mode 3: Pressure Mode

Fast questions. Limited preparation time.

---

# BLOCKED ACTIONS

* No skipping recording step
* No skipping playback step
* No skipping self-evaluation step

---

# VOICE UX PRINCIPLE

User must hear themselves before system feedback.

Self-awareness is primary learning mechanism.

---

# CORE DESIGN RULE

The system does not "teach answers".

It trains performance under pressure.

---

# FINAL OUTCOME

User should gradually transform from:

Unstructured speaker → structured candidate → confident interview performer
