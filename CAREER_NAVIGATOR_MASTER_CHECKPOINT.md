CAREER NAVIGATOR — MASTER CHECKPOINT v1.0
1. Видение проекта

Career Navigator — это не приложение с игровыми элементами.

Это однопользовательская сюжетная игра о профессиональном развитии, где пользователь проходит путь от новичка до специалиста, изучая профессию через путешествие по художественному миру.

Главная цель проекта — создать продукт, который люди будут помнить не из-за чек-листов, а из-за эмоций.

2. Главный принцип

Пользователь никогда не должен чувствовать, что он переключается между экранами приложения.

Он должен ощущать, что путешествует внутри одного живого мира.

Каждое действие — часть путешествия.

Каждый экран — часть мира.

Каждая глава — новое место.

3. Что НЕ является целью

Мы не делаем:

очередной ToDo;
очередной Learning App;
очередной Career Tracker;
очередной Resume Builder.

Все эти функции существуют только как игровые механики.

5. Основная идея мира

Каждая профессия — отдельный художественный мир.

Например:

Software Engineer

↓

The Code Archipelago

Designer

↓

The Creative Islands

↓

The Observatory

Cyber Security

↓

The Fortress

AI Engineer

↓

The Neural Citadel

Каждая профессия полностью меняет атмосферу приложения.

6. Архитектурная философия

Существует только один мир.

Существует только один HUD.

Существует только один источник данных.

Любое дублирование запрещено.

7. Разделение ответственности

WorldRenderer

Отвечает только за мир.

JourneyHUD

Отвечает только за интерфейс.

Skill Engine

Отвечает только за прогресс.

Event Bus

Отвечает только за события.

WorldTheme

Отвечает только за визуальную идентичность профессии.

8. Что считается готовым

Архитектура считается практически завершённой.

Дальнейшие изменения архитектуры допускаются только при серьёзной необходимости.

Новые функции не должны ломать существующую структуру.

9. Новый этап проекта

Мы прекращаем разработку новых экранов.

Мы прекращаем постоянные рефакторинги.

Мы начинаем строить мир.

11. World Pipeline

Каждая профессия содержит:

world.ts

missions.ts

resume.ts

Никакой логики внутри художественных файлов.

12. Художественная философия

Мы не строим карту.

Мы строим произведение искусства.

Игрок путешествует по большой вертикальной иллюстрации.

Камера исследует уже существующий мир.

Мир не генерируется кодом.

Мир создаётся художником.

13. Monument Valley Principle

Главный референс проекта:

Monument Valley

Но мы не копируем её.

Мы заимствуем философию:

простота;

архитектура;

тишина;

свет;

масштаб;

ощущение открытия.

14. UX Philosophy

Любое действие должно выполняться максимум за 2–3 касания.

Игрок никогда не должен искать нужную кнопку.

Интерфейс не должен отвлекать от мира.

16. Правила разработки

Никогда не создавать вторую реализацию существующей системы.

Никогда не менять архитектуру без отдельного решения.

Никогда не выполнять большой рефакторинг одновременно с UX.

Никогда не смешивать новую и старую системы.

Если ответ "нет", значит изменение не является приоритетным.
